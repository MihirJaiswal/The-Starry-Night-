# The Starry Night

An animated, brush-stroke recreation of Van Gogh's *The Starry Night* (1889), written as a single WebGL 2 fragment shader with no libraries.

Every part of the painting is built from individual strokes: the sky strokes follow a swirl flow field, the hill strokes run along the ridgelines, and the cypress strokes rise like flames. Each stroke has its own colour, bristle texture and impasto relief. Move the pointer over the sky to stir the strokes.

Open `index.html` in any browser with WebGL 2.
